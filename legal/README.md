# Legal

Documentos jurídicos e de licenciamento do GPT Project Toolkit.

A raiz mantém apenas os arquivos que o GitHub e contribuidores precisam encontrar imediatamente:

- `../LICENSE.md` — mapa de escopo do repositório;
- `../CONTRIBUTING.md` — processo de contribuição.

## Arquivos

| Arquivo | Função |
|---|---|
| `LICENSE-SOFTWARE.md` | aplicação da PolyForm Noncommercial 1.0.0 às Skills e ativos operacionais |
| `LICENSE-DOCUMENTATION.md` | aplicação da CC BY-NC-SA 4.0 à documentação/metodologia |
| `COMMERCIAL_LICENSING.md` | política e canal para direitos comerciais separados |
| `CONTRIBUTOR_LICENSE_AGREEMENT.md` | CLA exigido para contribuições externas |
| `COMMERCIAL_LICENSE_TEMPLATE.md` | modelo não vinculante para eventual contrato comercial |
| `LEGAL_POSITION.md` | postura jurídica operacional atual |
| `THIRD_PARTY_NOTICES.md` | proveniência e materiais de terceiros |

## Regra

`../LICENSE.md` é o ponto de entrada. Estes arquivos detalham funções específicas sem competir com o mapa de escopo da raiz.
